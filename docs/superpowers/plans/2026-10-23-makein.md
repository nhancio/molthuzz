# MakeIn Implementation Plan

> Execute the interface and Firebase portions using superpowers:subagent-driven-development. Deployment and provider integration are coordinated in this session.

**Goal:** Convert the recovered MoltHuzz repository into MakeIn, an adult dating app with Google login, onboarding, swipe/like, matches/chat, and ₹2 first month followed by ₹99 monthly billing.

**Architecture:** Universal Expo root app. Firebase client Auth, Firestore and Storage, enforced Firestore rules. Netlify functions for Razorpay checkout, signed webhooks, cancellation and verified server entitlements. Existing web/backend retained as legacy reference.

**Tech Stack:** Expo 58, React Native, TypeScript, Firebase, Netlify functions, Razorpay.

**Spec:** docs/superpowers/specs/2026-10-23-makein-design.md

## Global Constraints
- MakeIn is for adults 18+.
- ₹2 for the first calendar month, then ₹99/month in INR.
- Samples are demo only; no fabricated accounts, matches, messages or payment success.
- Exact owner email is pending user clarification; no project creation under a guessed owner.
- Server alone writes entitlements; demo requires no payment.
- Native bundle IDs: com.nhancio.makein. Expo slug: makein.
